## This directory contains important books recommended by experts in the field.

### 1. Programming Massively Parallel Processors
- This is a book on programming massively parallel processors, a hands-on approach.
- This book is referred by **GPU MODE** and **UIUC GPU Teaching Toolkit**.
- **GPU MODE:** [YouTube Channel](https://www.youtube.com/@GPUMODE)
- **UIUC GPU Course:** [Course Link](http://gputeachingkit.hwu.crhc.illinois.edu/) *(May require DNS or VPN)*
- **PDF:** [Programming Massively Parallel Processors](Books/1.%20programming-massively-parallel-processors-a-hands-on-approach.pdf)
